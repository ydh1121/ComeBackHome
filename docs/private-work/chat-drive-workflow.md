# 자료를 올리고 답변을 함께 보는 방법

이 기능은 기존 ChatGPT 대화와 연결된 비공개 Google Drive를 사용합니다. GPT API 키나 별도 유료 분석 서비스는 필요하지 않습니다.

## 자료를 올리는 사람

1. 산재 → 자료함 → **자료 올리기**를 엽니다.
2. 사진·PDF를 한 번에 선택하고 **파일 보관**을 누릅니다. 메모는 **메모 한 번에 추가**에 적습니다.
3. 파일 옆에 **보관 완료**가 표시되면 끝입니다. 자료를 읽고 정리한 내용은 **답변 보기**에서 함께 볼 수 있습니다.

## ChatGPT에 물어보는 사람

1. 관리자 계정으로 자료함을 열고 함께 볼 자료를 선택합니다.
2. 궁금한 점을 적고 **ChatGPT에 물어보기 준비**를 누릅니다.
3. **복사**를 누르고 평소 사용하는 이 ChatGPT 계정의 대화에 붙여 넣습니다. 그 대화에 Google Drive가 연결되어 있어야 합니다.
4. ChatGPT가 요청문에 지정된 Drive 문서의 내용을 답변으로 바꾸도록 합니다. 새 문서를 다른 곳에 만들면 앱에서 읽지 못할 수 있습니다.
5. 자료함 → **답변 보기 → 답변 확인**을 누릅니다. 두 계정에서 같은 답변을 읽을 수 있습니다.
6. 답변에 준비할 일·메모 제안이 있으면 **추가할 내용 확인**을 누릅니다. 내용을 살펴보고 원하는 항목만 저장합니다.

답변을 읽는 것만으로 기관 결정·진단·지급금액이 확정되거나 원본이 이동하지 않습니다. 파일 정리는 별도의 확인 버튼으로 진행합니다.

## 문제가 생겼을 때

- 요청 준비 중에 화면을 닫았다면 **답변 보기 → 준비 이어하기**를 누릅니다. 요청이 아직 처리 중이면 잠시 후 다시 시도합니다. 원본 파일을 다시 올릴 필요는 없습니다.
- ChatGPT가 Drive 문서를 수정할 수 없다고 하면 답변 JSON을 파일로 받아 **답변 직접 가져오기**에서 선택합니다. 요청문에 지정한 응답 JSON과 기존 분석 결과 JSON을 모두 읽을 수 있습니다.
- 요청한 뒤 선택한 원본·메모가 바뀌었다면 최신 자료로 새 요청을 준비합니다. 오래된 분석을 현재 자료의 결과처럼 저장하지 않습니다.

## 예약 분석

예약 실행은 ChatGPT에서 별도로 설정하는 작업입니다. 앱에 자료를 올리는 것만으로 ChatGPT 대화가 자동 실행되지는 않습니다. 연결된 Drive 문서를 읽고 **같은 응답 문서**를 수정할 수 있는지 먼저 수동으로 확인해야 합니다. 예약 작업의 모델·추론 강도와 요금제 변경 시 동작은 해당 ChatGPT 화면에서 확인합니다.

## 구현·검증 범위

- 앱이 만든 Google 문서를 응답 보관함으로 사용합니다. 기존 `drive.file` 권한을 유지하며 임의의 Drive 파일을 검색·수집하지 않습니다.
- 현재 계정의 서버 권한, 보관 폴더와 문서의 비공개 권한, 선택한 원본의 SHA·메모 수정 번호를 확인합니다.
- 답변을 가져오는 동안 문서 버전이 바뀌면 읽기를 중단합니다. 답변은 코드로 실행하거나 HTML로 삽입하지 않습니다.
- 요청 재시도는 저장된 요청 ID와 Drive 앱 속성으로 복구합니다. 원본을 삭제하지 않습니다.
- 제안 저장은 기존의 명시적 승인·원자적 D1 저장·세션 검증 경로를 그대로 사용합니다.
- 검증 명령: `node scripts/verify-chat-drive-exchange.mjs`. 합성 로컬 SQLite와 모의 Drive 테스트이며, 실제 계정 간 Drive 연결 검수와 구분합니다.
- 운영 적용에는 추가 테이블 마이그레이션 `0014_chat_exchanges.sql`이 필요합니다. 기존 일정 테이블은 변경하지 않습니다.
