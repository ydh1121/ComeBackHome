# 기존 산재 어드바이저의 재취업 안내

검토 기준: 2026-10-30. 기존 `오늘`과 `상황별 도움말`에서 **다른 직장에 취업해도 될까요?**로 들어간다. 현재 상태와 취업 예정·시작 여부만 선택한다. 기존 A–L 안내, 직장 관리, 지급장부, 계산 도구를 유지한다.

## 화면과 기록의 경계

- 신청·심사, 요양 중, 요양종결, 장해급여 이후, 구직급여 수급 중을 구분한다. 상태를 모를 때는 확인할 자료부터 안내한다.
- 선택은 화면 안에서만 유지하며 저장하거나 기관 결정으로 추정하지 않는다.
- 다음 행동, 이유, 서류, 의사·기관에 물어볼 문장을 제공한다. 기존 편집·복사·수정이력·동시 편집 충돌 계약을 사용한다. 구직급여 취업신고에 의사 소견이 필수라고 안내하지 않는다.
- 기존 직장의 입사·근무 날짜, 업무, 시간, 임금을 읽는다. 실제·예정·불명확한 기록, 열린 기간, 잘못된 날짜를 구분한다. 계약 종료 예정일을 실제 마지막 근무일로 쓰지 않는다.
- 재직·근무 범위와 요양·급여 기록 기간을 비교한다. 겹친다는 사실은 매일 실제로 근무했다는 증거나 수급자격 판단이 아니다. 직장과 지급장부에도 같은 확인 안내를 표시한다.
- 안내 열람, 두 질문 선택, 기간 비교는 기존 자격·금액·기간·결정·입금·기한을 변경하지 않는다. 안내 문구를 명시적으로 저장할 때만 기존 content 레코드가 바뀐다.
- 재발·악화와 새 업무상 재해를 구분해 의료진·공단에 확인하게 한다. 산재 이력이 취업을 일률적으로 금지하거나 모든 회사에 자동 통보된다고 안내하지 않는다.

## 검증 경로

`node scripts/verify-private-advisor.mjs`에 순수 기간 모델 검증을 연결했다. 기존 격리 D1 브라우저 harness에 6상태×2취업상태, 안내 열람 중 쓰기 0, 기존 기록·지급장부 불변, 네 가지 기간 확인, 기존 화면 연결, 편집 취소·복사·명시 저장·충돌·이력을 추가했다. Chromium/WebKit 375·390·768·1024·1440 폭을 검사한다. 모든 테스트 자료는 합성이다.

실제 사용자가 선택한 비공개 자료의 ChatGPT 답변 검증은 별도 비공개 증거로 관리한다. 해당 원본, 문서 ID, 답변 내용은 이 저장소나 CI에 넣지 않는다. 답변 불러오기와 제안의 명시 저장·원본 이동은 별도 동작이다.
