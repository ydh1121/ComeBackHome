# 자료와 메모를 한 번에 정리하기

새 버전의 **산재 → 내 관리함 → 자료·메모**에서 사용합니다. 일반적인 사용에는 별도 설치나 API 키가 필요하지 않습니다.

## 1. 파일과 메모 모으기

**파일 여러 개 추가**를 누르고 사진이나 PDF를 함께 선택하세요. 이어 **선택한 N개 파일 보관**을 누르면 연결된 비공개 Google Drive 폴더에 저장합니다. 파일은 한 번에 20개, 하나당 20MB, 전체 100MB까지 선택할 수 있습니다.

적어 둔 내용은 **메모 한 번에 추가**에서 붙여 넣으세요. TXT·MD 파일도 여러 개 선택할 수 있습니다. 내용을 확인한 뒤 **메모 한 번에 저장**을 누릅니다.

파일 옆에 **보관 완료**가 표시되면 사용할 준비가 된 것입니다. 일부 파일만 실패했다면 해당 파일의 **재시도**를 누르세요. 완료된 파일을 다시 올릴 필요는 없습니다.

## 2. 함께 분석할 자료 선택하기

파일과 메모 왼쪽의 체크박스를 선택하세요. 여러 개를 한꺼번에 선택할 수 있습니다. 궁금한 점을 적거나 비워 두고 **GPT 분석 요청 한 번에 준비**를 누르세요.

준비된 요청문을 **복사**해서 ChatGPT에 한 번에 전달하면 됩니다. 파일이 자동으로 전송되지는 않습니다. ChatGPT가 비공개 링크를 읽지 못한다고 하면, 본인이 허용하는 방식으로 해당 파일을 전달하세요. 읽지 못한 파일을 읽었다고 전제한 답변은 사용하지 마세요.

## 3. 답변을 앱에 담기

ChatGPT 답변에는 설명과 앱에 가져올 JSON이 포함됩니다. **GPT 답변을 준비할 일·메모로 가져오기**를 열고 아래 중 편한 방법 하나를 사용하세요.

- JSON 파일을 받았다면 **분석 결과 파일 가져오기**에서 선택합니다.
- 답변에 JSON 코드가 있다면 그 부분만 **GPT 분석 결과**에 붙여 넣고 **내용 확인**을 누릅니다.

제목, 내용, 연결된 원본, 들어갈 항목을 확인하세요. 준비할 일뿐 아니라 직장 이력·진료·기관 서류 등도 알맞은 항목으로 제안할 수 있습니다. 넣지 않을 항목의 체크를 해제한 뒤 **선택한 N개 새 기록으로 저장**을 누르세요.

분석만으로 진단·승인·지급액을 확정하지 않습니다. 확인이 필요한 날짜나 금액은 본문에 남겨 두며, 기관 결정이나 실제 입금으로 자동 처리하지 않습니다. 기존 기록과 원본도 덮어쓰지 않습니다.

## 4. Drive 폴더 정리하기

분석 답변에 분류 제안이 있으면 **파일 정리 제안**이 함께 표시됩니다. 직접 정리하려면 목록에서 파일을 고른 뒤 **선택한 파일을 분야별로 정리**를 여세요.

각 파일의 **보관할 분야**를 확인하거나 바꾸고 **선택한 파일 N개 정리**를 누릅니다. 신청·진행, 진료·치료, 직장·고용보험, 비용·지급, 연락·기관 회신, 기타 자료 중에서 선택할 수 있습니다. 기존 비공개 보관 폴더 안에 분야별 폴더를 만들고 원본을 옮깁니다. 파일 내용·링크·공유 설정은 유지합니다.

기록 저장과 폴더 정리는 서로 별도입니다. 기록을 저장했다는 이유로 파일이 옮겨지지 않습니다.

정리 도중 오류가 나면 **미완료 N개 다시 확인**을 누르세요. 이미 옮겨진 파일인지부터 확인하므로, 완료된 파일을 다시 올리거나 지울 필요가 없습니다. 진행 중이던 파일은 같은 분야로 재시도하세요. 계속 실패하면 파일을 직접 삭제하지 말고 오류 안내를 전달해 주세요.

## 선택사항: 답변을 직접 보내는 분석 도구

**분석 도구 연결 · 선택사항**은 API로 답변을 보낼 수 있도록 구성된 도구가 있을 때만 사용합니다. 일반 ChatGPT 대화에는 위의 복사·파일 가져오기 방식이면 충분합니다.

연결을 만들면 선택한 자료의 답변만 받을 수 있는 1시간짜리 정보가 나옵니다. 신뢰하는 도구에만 전달하고 공개 게시물이나 문서에 보관하지 마세요. 이 연결은 원본을 읽거나 파일을 옮기는 권한이 없습니다. 답변이 도착해도 **답변 가져와 검토**를 눌러 확인하고 저장해야 반영됩니다.

로그아웃하거나 연결을 취소하면 해당 연결은 사용할 수 없습니다. 분석 중 자료가 바뀌면 새로 요청해야 합니다. 별도 분석 도구가 없다면 이 영역은 설정하지 않아도 됩니다.
