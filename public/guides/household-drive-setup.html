생활비·할 일로 돌아가기

가계부를 Drive에 보관하려면

이미 연결한 Google 계정과 프로젝트를 그대로 사용해요. 새 계정이나 API 키를 만들 필요는 없어요.

먼저 앱에서 확인하세요

  1. 상단의 생활비·할 일을 열고 가계부 시작하기를 눌러요.
  2. 가계부가 열리면 설정은 끝이에요. 두 계정이 같은 장부를 사용해요.
  3. Google Sheets API를 켜 주세요라는 안내가 나올 때만 아래를 진행하세요.

Google Sheets API 켜기 — 최초 한 번

  1. Drive 연결을 설정했던 Google 계정으로 Google Sheets API 설정을 열어요.
  2. 화면 맨 위의 프로젝트 이름을 눌러 ComeBackHome의 Drive 연결에 사용했던 프로젝트를 선택해요. 새 프로젝트를 만들지 마세요.
  3. 어느 프로젝트인지 헷갈리면 프로젝트의 설정 → 프로젝트 번호를 확인하세요. 이전에 Cloudflare에 등록한 PRIVATE_DRIVE_APP_ID와 같은 번호예요. 이 값은 새로 만들거나 바꾸지 않아요.
  4. 사용 버튼을 누르세요. 이미 관리가 보이면 켜져 있는 상태예요. 결제나 유료 요금제 신청은 필요하지 않아요.
  5. ComeBackHome으로 돌아와 가계부 시작하기 또는 다시 확인을 눌러요.
프로젝트 번호를 찾기 어렵거나 다른 오류가 나오면 그 화면만 알려 주세요. 비밀번호, API 키, 카드번호를 보내지 마세요.

기록은 어디에 있나요?

앱이 현재 연결한 비공개 폴더에 우리집 가계부 시트를 만들어요. 앱의 가계부 설정에서 Drive에서 장부 보기를 누르면 열 수 있어요. 기록 수정은 앱에서 해 주세요. 시트의 계산식이나 원본 열을 직접 바꾸면 서로 다른 금액이 저장되지 않도록 동기화가 멈춰요.

알림 받기

두 사람이 각각 자신의 PWA에서 가계부 설정 → 이 기기에서 받기를 한 번 눌러요. 가계부 자정 알림과 할 일 알림은 같은 화면에서 켜고 끌 수 있어요. iPhone에서는 홈 화면에 추가한 PWA로 열어 주세요.
